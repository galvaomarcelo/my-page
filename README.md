# Marcelo Galvão — modern personal page

This is a clean replacement for the old Bootstrap/resume-style page.

## Folder structure

```text
my-page/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── scripts.js
└── assets/
    ├── img/
    └── video/
```

## Add your videos

Create:

```text
assets/video/farm-management.mp4
assets/video/geoar.mp4
assets/video/drone-vision.mp4
```

The page will automatically show the native HTML5 video controls.

Recommended screen recordings:
- MP4 / H.264
- 1080p or 720p
- 30–90 seconds
- Keep each video below roughly 10–20 MB if possible

## Add posters

Optional:

```text
assets/img/farm-management-poster.jpg
assets/img/geoar-poster.jpg
assets/img/drone-poster.jpg
```

## Replace these placeholders

In `index.html`:
- `YOUR_EMAIL@example.com`
- LinkedIn `href="#"`
- CV path if your CV has a different filename
- Case study `href="#"`
- Google Scholar URL

The existing `assets/img/profile3.jpg` is reused.
